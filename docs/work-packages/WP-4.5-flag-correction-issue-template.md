# WP-4.5 — "Flag a correction / takedown" issue template
Phase: 4 · Tier: haiku · Depends on: none

## Read first
- `docs/editorial-policy.md` (documented takedown path)

## Scope
- A GitHub issue template for readers or the maintainer to flag a factual error, a rights/takedown concern, or another correction on a specific work.
- Fields: work id, issue type (factual error / rights concern / other), description, requested action.

## Files
`.github/ISSUE_TEMPLATE/correction-takedown.yml`

## Acceptance
- The template's YAML frontmatter is valid and renders correctly in GitHub's "new issue" template picker (verify via manual review of the YAML structure against GitHub's issue-forms schema).

## Out of scope
- Any automation that acts on submitted issues.
